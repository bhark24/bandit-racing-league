Geezer App Dashboard Redesign Preview

A visual mockup demonstrating a balanced layout while retaining all built features.

Redesign Highlights

  • Balance: The relative stands table is expanded vertically to occupy the center, getting rid of the empty blank center void.
  • Decluttering: Setup buttons are hidden from the driving UI, and pit checkboxes are cleanly aligned.
  • Contrast: Dimmer labels and high-contrast monospaced data values make it easy to read telemetry instantly.
